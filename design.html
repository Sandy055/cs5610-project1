Design Document

Project Description

This project is a personal homepage developed entirely with Vanilla HTML5, CSS3, and ES6+ JavaScript. It serves as an interactive portfolio to showcase web development projects without relying on external UI component libraries like Bootstrap or jQuery. The page includes custom features such as a 3D tilting card effect powered by ES6 modules.

User Personas

Persona 1: Tech Recruiter (Sarah)

Background: Sarah is a technical recruiter looking for junior web developers who understand core web technologies.

Goals: She wants to quickly assess the candidate's coding skills, view their portfolio, and find contact information or GitHub links.

Persona 2: Fellow Developer (Alex)

Background: Alex is a student or peer developer looking for inspiration on how to build vanilla JavaScript interactions.

Goals: Alex wants to see clean, readable source code, creative CSS implementations, and understand the logic behind custom effects.

User Stories

  • As Sarah, I want to see a clear list of projects on the homepage so that I can quickly gauge Yufei Ge's technical capabilities.
  • As Alex, I want to hover over the project cards and see a dynamic 3D tilt effect so that I am impressed by the interactive UI.
  • As a visitor, I want to easily navigate between the homepage, the design document, and the AI gallery using a consistent top navigation bar.

Design Mockups

The layout follows a clean, single-column design on mobile that expands into a responsive CSS Grid on desktop. The primary colors are a sleek dark palette with high-contrast text to give a modern, developer-focused aesthetic.
